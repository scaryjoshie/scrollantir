  bespoke Python agent loop. See memory file
  `feedback_custom_vs_offtheshelf.md` for why. Locked in; don't
  re-litigate.

  sessions on this project. Set via:
  - `~/scrollantir-scratch/.claude/settings.json`
  - `/Users/joshua/dev/scrollantir/.claude/settings.local.json`
    (gitignored so OSS consumers don't inherit bypass)
- **Source / data / tag ontology** (from `docs/architecture.md`
  §"Source vs. data vs. tags"): workspace / container / tab-name
  live in **`data`**, not `source`. Container is a *context*, not a
  *project identity*. Project classifier (roadmap #8) synthesizes
  attribution from multiple signals; don't collapse at ingest time.
- **cmux per-tab watcher deferred** (`docs/cmux-watcher.md`) —
  workspace-level is already free via `system.window.title`; tab
  detail only becomes worth tracking when a downstream consumer
  needs it.
- **Hostname-agnostic UUID scheme** on Mac:
  `uuid5(NS, "mac:{source}:{bucket_created_at}:{aw_id}")`. Hostname
  lives in AW bucket_ids which drift with DHCP — the old scheme
  would have re-ingested all history on Wi-Fi changes. See commit
  `3a8348d`.

## Cleanup SQL pattern (AW heartbeat-cascade dedup)

Run weekly-ish until the forwarder-side suppression lands. Do it in
a transaction with sanity check:

```sql
DELETE FROM public.events a
USING public.events b
WHERE a.source = '<source>' AND a.device = 'mac'
  AND b.source = '<source>' AND b.device = 'mac'
  AND a.id <> b.id
  AND b.data = a.data                                -- window / zen.tab
  -- OR: b.data->>'status' IS NOT DISTINCT FROM a.data->>'status'  -- afk
  AND b.timestamp_utc <= a.timestamp_utc
  AND b.timestamp_utc + make_interval(secs => b.duration_s)
      >= a.timestamp_utc + make_interval(secs => a.duration_s)
  AND (b.duration_s > a.duration_s
       OR (b.duration_s = a.duration_s AND b.id > a.id));
```

Verify `COUNT(*)` overlap pairs = 0 and per-source hours < wall-clock
window before committing.

## Gotchas / surprises saved for posterity

- **Keychain "Always Allow" prompt** fires when the venv python
  first reads `scrollantir/ingest-token`. Click *Always Allow*, not
  *Allow* (one-time). Re-prompts if the venv is rebuilt.
- **Supabase direct connection is IPv6-only.** Use Session Pooler
  URL for anything running from an IPv4-only network
  (`aws-1-us-east-2.pooler.supabase.com:5432` for this project).
  Admin CLI auto-detects by host suffix.
- **Edge functions deployed with `--no-verify-jwt`.** Our bearer
  tokens aren't JWTs; Supabase's gateway would reject them
  otherwise.
- **`pgcrypto` lives in `extensions` schema on Supabase**, not
  `public`. Call sites use `extensions.digest(...)`.
- **`events_enriched` view grants drop on `CREATE OR REPLACE VIEW`.**
  Any schema change that touches the view must re-run
  `GRANT SELECT ON public.events_enriched TO agent_role, user_role;`.
- **Bypass permissions for Claude Code** is the project default
  (both in scratch dir and repo-local settings). Do not "fix" it
  back to prompting.
